Project Overview
This capstone project focuses on building an end-to-end Smart City Traffic Intelligence solution using the Metro Interstate Traffic Volume dataset.

The project is divided into three connected parts:

Part 1 – Data Analytics
SQL Data Analysis
Descriptive Statistics
Correlation Analysis
Probability Analysis
Power BI Dashboard Development
Part 2 – Python Analytics Pipeline
Data Pipeline Construction
Data Cleaning and Validation
Feature Engineering
Data Visualisation
Command-Line Analytics Application
Logging and Reproducibility
Part 3 – Machine Learning and AI
Supervised Learning
Unsupervised Learning
Deep Learning
Explainable AI (SHAP/LIME)
Recommendation System
MLOps and Deployment Simulation
Responsible AI Assessment
Dataset
Dataset: Metro Interstate Traffic Volume

Traffic Volume
